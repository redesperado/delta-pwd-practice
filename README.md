- **独立电报音试听**：点击卡片“🔊 试听发音”，独立调用摩斯发生器预览该组 4 位音频，实战前预习听感。

### 2. 实战模拟开门模式 (Tactical Cipher Lock)
- **机制还原**：完全对齐游戏内密码门机制，循环播放电报音，每播完一轮有 **2.8 秒真实空白长停顿** 再继续下一轮循环。
- **初学者密码对照与明文答案**：新增【👁️ 显示密码 (新手对照)】切换按钮。初学者刚开始若听不懂，可一键展开当前题目的明文答案，并直接对照展示每位密码的摩斯点划与“几短几长”口诀，边听边学快速入门。
- **静音防扰机制**：**切换 Tab 或初次加载时绝对不自动播放音频**，必须由特战干员主动点击【开始播放】或按下【空格键】触发。
- **位数自由切换**：默认 **3 位数密码**（主流局内黑室与彩蛋门），支持一键切换 **4 位数密码**（航天基地与每日大门）。
- **极速手感**：输满位数后自动验证开锁，成功触发“DOOR UNLOCKED”通行动画与音效，显示通关耗时；错误时红色报警并防锁死提示。
- **拟真小键盘**：完美映射物理小键盘、主键盘数字键、Backspace 退格与 Enter 确认。

### 3. 单字本能条件反射突击 (Instinct Reaction)
- **听音秒辨**：随机生成 0~9 单个数字的摩斯电码，进入时不自动发声，点按【再听一次】或【空格键】播放。
- **竞技仪表盘**：实时统计 **连击数 (COMBO)**、**最佳连击**、**辨识正确率 %** 与 **平均响应毫秒 (ms)**。
- **即时纠错**：回答错误立刻标红并展示标准对照（如“2短3长”），形成肌肉记忆。

### 4. 电脑终端屏幕视觉速算 (Terminal Cipher Hack)
- **机制还原**：还原游戏中黑客笔记本/电脑终端屏幕上的摩斯符号，锻炼肉眼眼力与速算心算。
- **前缀看破法则**：
  - **点 `·` 开头（1~5）**：数有几个点就是几（如 `···--` 为 3）。
  - **横 `-` 开头（6~9）**：以 5 为基底，5 加上后面的点数即为数字（如 `-····` = 5+1 = 6）。
  - **全横 `-----`**：即为 0。
- **秒表极限竞速**：记录破译耗时与神速纪录，展示速算推导过程。

### 5. 游戏声音实时听音破译 (Live Audio Morse Decoder) 【BETA · 测试中】
- **双模音频接入**：
  - **系统音频内录 (免麦克风)**：通过浏览器屏幕/窗口共享捕获系统声音，直接内录游戏声音，不受外界房间噪音干扰，准确率最高。特别优化了 Chromium 屏幕捕获生命周期，杜绝系统音频被意外切断。
  - **麦克风 / 立体声混音**：支持麦克风对准扬声器收音，或选用虚拟音频声卡。
- **底层硬件音频驱动 · 后台免休眠持续监听**：采用 Web Audio 底层音频硬件时钟（ScriptProcessorNode）驱动 DSP 状态机与滞后阈值分析，彻底解决浏览器标签页在玩家切换回全屏游戏时冻结 `requestAnimationFrame`（降为 0 fps）导致无法解码的难题。
- **一键自测验证 (无需进游戏)**：提供【🔊 播放自测音频 (382)】功能，支持内置合成管线直通分析，方便用户在开打对局前快速检验声卡采集与示波器反应。
- **Web Audio 窄带带通滤波抗噪**：中心频率可调（默认 750Hz 游戏标准蜂鸣，支持 500~1100Hz 微调与航天/大坝预设），有效过滤战场枪炮与脚步杂音；触发阈值默认调优至 10%，配合 2.8x 弱音增益，轻松捕获远距离微弱蜂鸣。
- **自适应状态机解码与容错**：毫秒级度量电平高低时间，识别点（·）与划（-），支持毛刺多余杂音后向截取容错，长空白停顿（1.8s）自动结算当前轮次。
- **明文密码永久锁定与破译历史**：动态示波器显示声波波形，大屏高亮展示最终解密密码，解码成果永久保留在液晶屏与历史列表中（静音时不抹除），提供一键复制至剪贴板与近 5 次历史记录。

## ☁️ 部署到 Cloudflare Pages 指南

本项目为**纯静态、零构建依赖、开箱即用架构**，并且已针对 Cloudflare Pages 的 HTTPS 环境优化了 Web Audio API 的用户交互激活机制，并配备了 `_headers` 与 `wrangler.toml` 配置文件，保证 100% 部署无任何问题：

### 方法一：Cloudflare Dashboard 网页拖拽直接部署 (最快，仅需10秒)
1. 登录 [Cloudflare 控制台](https://dash.cloudflare.com/)。
2. 点击左侧导航栏的 **Workers 和 Pages** ➔ **创建应用程序** ➔ 选择 **Pages** 选项卡。
3. 点击 **上传资产 (Upload assets)**。
4. 输入项目名称（如 `delta-morse`）。
5. 直接将本项目所在的整个 `d:\project\Delta` 文件夹拖入网页上传区域。
6. 点击 **部署站点 (Deploy site)**，即可获得由 Cloudflare 全球 CDN 分发的专属域名（如 `https://delta-morse.pages.dev`）！

### 方法二：通过 GitHub 仓库自动持续部署 (推荐)
1. 将当前项目上传到您的 GitHub 仓库。
2. 在 Cloudflare Pages 中选择 **连接到 Git (Connect to Git)** 并选中该仓库。
3. 构建设置（Build Settings）：
   - **框架预设 (Framework preset)**：选择 `None`。
   - **构建命令 (Build command)**：留空（不需要构建）。
   - **构建输出目录 (Build output directory)**：填入 `.`（根目录）。
4. 点击 **保存并部署** 即可！以后每次 git push 都会全自动秒级部署。

### 方法三：使用 Cloudflare Wrangler CLI 命令行部署
在终端进入项目根目录执行：
```bash
npx wrangler pages deploy .
```
按照终端提示授权登录即可全自动上传发布。
